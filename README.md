# $PONSFIELD — Lord Ponsfield

Одностраничный лендинг под мемкоин Lord Ponsfield (кот-лендлорд, "fat cat" в
идиоматическом смысле). Чистый статический HTML/CSS/JS, без сборки.

## Структура
- `index.html` — вся разметка
- `style.css` — стили (тема: тёмный фон + золото/бронза + зелёный твид)
- `script.js` — конфиг ссылок/CA (`CONFIG` в начале файла) + копирование CA +
  подтяжка live-цены с DexScreener, если CA указан
- `assets/ponsfield-mascot.jpg` — фото маскота

## Перед публикацией заполнить
Открой `script.js`, в объекте `CONFIG` в начале файла впиши:
- `CA` — адрес контракта, когда токен будет заминчен
- `BUY_URL` — ссылка на покупку (pump.fun / DEX / лаунчпад)
- `CHART_URL` — ссылка на график (можно оставить пустым — подставится
  DexScreener по CA автоматически)
- `X_URL`, `TELEGRAM_URL` — соцсети

Пока `CA` пустой, сайт честно показывает "TBD" / "Not deployed yet" вместо
выдуманных цифр — это ожидаемо и по дизайну.

## Деплой
1. Залить папку как есть на GitHub (веб-интерфейсом, drag-and-drop).
2. В Vercel → Add New Project → импортировать репозиторий. Build command не
   нужен, это статические файлы.
3. После покупки домена — подключить через Vercel → Settings → Domains.
